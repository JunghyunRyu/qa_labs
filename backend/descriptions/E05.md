## 문제 설명

새로 오픈한 **'파이썬 랜드(Python Land)'** 놀이공원의 입장권 판매 시스템을 구축하고 있습니다.
이 시스템은 고객의 **나이(만 나이)**를 입력받아 자동으로 입장료를 계산해 줍니다.

개발팀에서 `calculate_admission_fee` 함수를 구현해 전달했습니다. 하지만, 나이 구간이 바뀔 때 요금이 잘못 계산되거나, 말도 안 되는 나이가 입력되었을 때 시스템이 꼬이는 문제가 있다고 합니다.

QA 엔지니어인 여러분이 **경계값 분석(Boundary Value Analysis)** 기법을 활용해, 손님이 10원이라도 더 내거나 덜 내는 일이 없도록 꼼꼼하게 검증해 주세요!

## 함수 명세

```python
def calculate_admission_fee(age: int) -> int:
    pass
```

### 요금 정책

입장료의 기본 가격(Base Price)은 10,000원이며, 나이에 따라 아래와 같이 할인이 적용됩니다.

| 연령대 | 나이 구간 | 할인율 | 요금 |
|--------|-----------|--------|------|
| 어린이 | 0세 ~ 12세 | 50% 할인 | 5,000원 |
| 청소년 | 13세 ~ 18세 | 30% 할인 | 7,000원 |
| 성인 | 19세 ~ 64세 | 할인 없음 | 10,000원 |
| 노인 | 65세 ~ 120세 | 40% 할인 | 6,000원 |

### 지켜야 할 규칙

시스템의 안정성을 위해 다음 규칙을 엄격히 지켜야 합니다.

- **나이 범위**: 나이는 0보다 작거나 120보다 클 수 없습니다. 이 경우 반드시 `ValueError`가 발생해야 합니다.
- **데이터 타입**: 나이는 오직 **정수(Integer)**만 입력 가능합니다. 소수점, 문자열 등이 들어오면 `TypeError`가 발생해야 합니다.
- **결과값**: 계산된 요금은 반드시 정수(`int`) 형태여야 합니다.

## 정상 동작 예시

올바르게 구현된 코드는 다음과 같이 동작합니다.

```python
calculate_admission_fee(10)   # 어린이: 50% 할인 -> 5000
calculate_admission_fee(15)   # 청소년: 30% 할인 -> 7000
calculate_admission_fee(30)   # 성인: 정가 -> 10000
calculate_admission_fee(70)   # 노인: 40% 할인 -> 6000
```

## 테스트 힌트

- **경계값 분석**: 할인이 변경되는 나이인 `12세와 13세`, `18세와 19세`를 꼭 확인해 보세요. 개발자가 `<=`를 써야 할 곳에 `<`를 쓰는 실수를 자주 합니다.
- **동등 분할**: 각 연령대(어린이, 청소년, 성인, 노인) 중간에 있는 평범한 나이(예: 5세, 15세, 40세)도 테스트해 보세요.
- **예외 처리**:
  - `calculate_admission_fee(-1)` (태어나지 않은 사람?)
