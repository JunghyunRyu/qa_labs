## 문제 설명

우리는 지금 아주 간단한 **'계산기 앱'**을 만들고 있습니다. 이번에 추가할 기능은 두 숫자를 **빼는** 기능입니다.

개발자가 `sub`라는 빼기 함수를 만들어왔는데, 덧셈 때와 마찬가지로 엉뚱하게 동작하거나 숫자가 아닌 것도 받아들이는 버그가 있다고 합니다. QA 엔지니어인 여러분이 꼼꼼한 테스트를 작성해서 이 계산기가 튼튼하게 동작하는지 확인해주세요!

## 함수 명세

```python
def sub(amount_a: int, amount_b: int) -> int:
    pass
```

### 지켜야 할 규칙

이 계산기는 오직 **'정수(Integer)'**만 정확하게 처리해야 합니다.

- 숫자 `1`, `10`, `-5` 같은 정수는 OK!
- 소수점(`1.5`), 글자(`"Hello"`), 리스트(`[]`)는 절대 안 돼요. 입력되면 에러(`TypeError`)가 나야 합니다.
- 특히, `True`나 `False` 같은 불리언 값도 숫자로 취급하지 않도록 막아야 해요. (엄격하게!)
- 양수 빼기 (`10 - 5`), 음수 빼기 (`-5 - -10`), 0 빼기 (`10 - 0`) 모두 가능해요.
- 결과가 음수가 되어도 괜찮아요 (`5 - 10`).

## 정상 동작 예시

제대로 만든 함수라면 이렇게 동작합니다.

```python
sub(5, 3)      # 결과: 2
sub(3, 5)      # 결과: -2 (작은 수에서 큰 수를 뺄 때)
sub(-5, -5)    # 결과: 0
sub(10, -5)    # 결과: 15 (음수를 빼면 더하기가 되죠!)
```

## 테스트 힌트

여러분의 테스트 코드로 숨어있는 버그(Bug)를 찾아내야 합니다. 아래 같은 상황들을 테스트 코드로 작성해보세요.

- **기본 빼기**: `3 - 1`이 `2`가 잘 나오나요?
- **순서 확인**: 덧셈과 달리 뺄셈은 순서가 중요해요. `10 - 5`와 `5 - 10`은 다른 값이어야 합니다.
- **음수 처리**: 마이너스 값을 뺄 때(`10 - (-5)`) 숫자가 커지는지 확인해보세요.
- **함정 피하기**:
  - `sub(5.5, 2.0)`을 넣으면 에러가 나나요? (소수점 금지)
  - `sub(True, 1)`을 넣으면 에러가 나나요? (Python에서는 `True`가 `1`로 계산될 수 있어서 위험해요!)
