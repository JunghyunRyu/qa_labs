## 문제 설명

전자상거래 서비스에서 '주문하기' 버튼을 누르는 순간, 가장 먼저 실행되는 방어 로직입니다.
이 함수가 뚫리면 **빈 주문(Empty Order)**이 생성되거나, **대량 주문 공격**으로 인해 재고 시스템에 오류가 발생할 수 있습니다.

여러분의 목표는 `validate_cart_items` 함수가 비즈니스 규칙을 위반하는 모든 잘못된 요청을 정확히 **거절(False 반환)**하는지 검증하는 것입니다.

## 함수 명세

함수는 다음 규칙을 모두 만족할 때만 `True`를 반환해야 합니다. 하나라도 위반하면 `False`입니다.

```python
def validate_cart_items(items: list[str]) -> bool:
    pass
```

### 지켜야 할 규칙

- **입력 타입**: 반드시 `list`여야 합니다. (`None`, `dict` 등 불가)
- **수량 제한 (Count)**: 아이템 개수는 최소 1개 이상, 최대 10개 이하여야 합니다.
  - 0개 (빈 리스트) → `False`
  - 11개 이상 → `False`
- **아이템 유효성 (Item Validity)**:
  - 리스트의 모든 요소는 `str` 타입이어야 합니다.
  - 공백을 제거(`strip()`)했을 때 빈 문자열(`""`)이면 안 됩니다.

## 테스트 힌트

이 문제는 **경계값 분석(Boundary Value Analysis)**과 입력 데이터 검증이 핵심입니다.

**수량 경계값 테스트:**
- 유효 구간의 경계: 1개, 10개 (정상 동작 확인)
- 오류 구간의 경계: 0개, 11개 (거절 확인)
- Tip: 개발자들은 종종 `>`와 `>=`를 혼동하여 10개를 거절하거나 0개를 허용하는 실수를 범합니다.

**데이터 타입 및 내용 검증:**
- 리스트 안에 숫자가 섞여 있다면? `["item1", 123]`
- 눈에 보이지 않는 공백 문자열이라면? `[" ", "item2"]`
- 입력 자체가 리스트가 아니라면? `validate_cart_items("Not a list")`
