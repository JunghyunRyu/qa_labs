## 문제 설명

우리는 지금 아주 간단한 **'계산기 앱'**을 만들고 있습니다. 이 계산기의 가장 기초적인 기능은 두 숫자를 더하는 것입니다.

개발자가 `add`라는 더하기 함수를 만들어왔는데, 가끔 엉뚱하게 동작하거나 숫자가 아닌 것도 받아들이는 버그가 있다고 합니다. QA 엔지니어인 여러분이 꼼꼼한 테스트를 작성해서 이 계산기가 튼튼하게 동작하는지 확인해주세요!

## 함수 명세

```python
def add(amount_a: int, amount_b: int) -> int:
    pass
```

### 지켜야 할 규칙

이 계산기는 오직 **'정수(Integer)'**만 정확하게 처리해야 합니다.

**정수만 받아요:**
- 숫자 `1`, `10`, `-5` 같은 정수는 OK!
- 소수점(`1.5`), 글자(`"Hello"`), 리스트(`[]`)는 절대 안 돼요. 입력되면 에러(`TypeError`)가 나야 합니다.
- 특히, `True`나 `False` 같은 불리언 값도 숫자로 취급하지 않도록 막아야 해요. (엄격하게!)

**모든 정수 계산 가능:**
- 양수 더하기 (`10 + 20`)
- 음수 더하기 (`-5 + -10`)
- 0 더하기 (`10 + 0`)
- 결과가 음수가 되어도 괜찮아요.

## 정상 동작 예시

제대로 만든 함수라면 이렇게 동작합니다.

```python
add(2, 3)      # 결과: 5
add(10, -3)    # 결과: 7
add(-5, -5)    # 결과: -10
```

## 테스트 힌트

여러분의 테스트 코드로 숨어있는 버그(Bug)를 찾아내야 합니다. 아래 같은 상황들을 테스트 코드로 작성해보세요.

- **기본 더하기**: `1 + 1`이 `2`가 잘 나오나요?
- **빼기 같은 더하기**: `-5`를 더하면 숫자가 작아져야겠죠?
- **함정 피하기**:
  - `add(0.5, 0.5)`를 넣으면 에러가 나나요? (소수점 금지)
  - `add(True, 1)`을 넣으면 에러가 나나요? (Python에서는 `True`가 `1`로 계산될 수 있어서 위험해요!)
