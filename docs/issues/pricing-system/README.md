# QA Labs 요금제 시스템

## 개요

QA Labs 서비스의 유료화를 위한 요금제 시스템 구현 프로젝트입니다.

### 핵심 결정사항

| 항목 | 결정 |
|------|------|
| 결제 시스템 | 토스페이먼츠 |
| 요금제 구조 | 단일 유료 플랜 (옵션 A) |
| 런칭 목표 | 1개월 내 MVP |

---

## 요금제 구조

### Free (무료)
- **가격**: 0원
- **기능**:
  - 기본 코드 분석 (무제한)
  - AI 코칭: 월 10회
- **목적**: 서비스 체험, 바이럴 유도

### Premier (프리미어)
- **가격**: 월 19,900원 / 연 179,000원 (25% 할인)
- **기능**:
  - GPT-5.2 심층 분석
  - AI 코칭: 매일 10회 (월 300회+)
  - 통계 기반 맞춤 추천
- **목적**: 핵심 수익원

---

## 크레딧 정책

### 프레이밍 전략
- **"제한"이 아닌 "포함량"으로 표현**
- 예: "월 300회 제한" → "매일 10회 AI 코칭 제공"

### 크레딧 소진 시 옵션
1. **다음 달 기다리기** - 무료
2. **크레딧 팩 구매** - 5,000원 / 200회 (Phase 2)
3. **BYO-Key 연결** - 무료, 사용자 API 비용 (Phase 2)

## 1개월 타임라인

```
Week 1-2: Milestone 1 (결제 인프라 + 크레딧 시스템)
    │
    ├─ 토스페이먼츠 SDK 연동
    ├─ DB 스키마 설계 및 구현
    ├─ 구독 관리 API 개발
    ├─ 크레딧 카운팅 로직
    └─ 월간 리셋 스케줄러

Week 2-3: Milestone 2 (요금제 UI/UX)
    │
    ├─ 요금제 페이지
    ├─ 결제 플로우
    ├─ 크레딧 잔량 표시
    └─ 구독 관리 페이지

Week 3-4: Milestone 3 (테스트 및 런칭)
    │
    ├─ E2E 테스트
    ├─ 버그 수정
    ├─ 프로덕션 설정
    └─ 런칭

런칭 후 1-2개월: Milestone 4 (Phase 2)
    │
    ├─ 크레딧 팩 구매
    ├─ BYO-Key 연동
    └─ Lite 플랜 검토
```

## 기술 스택

### 백엔드
- **프레임워크**: FastAPI
- **ORM**: SQLAlchemy
- **작업 큐**: Celery + Redis
- **결제**: 토스페이먼츠 API

### 프론트엔드
- **프레임워크**: Next.js (React)
- **스타일링**: Tailwind CSS
- **결제 UI**: 토스페이먼츠 SDK

### 인프라
- **배포**: Docker + EC2
- **DB**: PostgreSQL
- **캐시**: Redis
