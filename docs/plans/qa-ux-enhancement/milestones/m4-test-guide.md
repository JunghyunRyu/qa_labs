## 테스트 체크리스트

### 1. Pre-loading 기능 테스트

#### 테스트 절차
1. 문제 목록에서 임의의 문제를 선택하여 진입
2. 페이지 로딩 직후 상단에 "Python 환경 준비 중..." 인디케이터 확인
3. 진행률 (0% → 100%) 변화 관찰
4. 초기화 완료 후 인디케이터 자동 숨김 확인

#### 기대 결과
- ✅ 페이지 진입 시 즉시 Pyodide 초기화 시작
- ✅ 진행률 UI 표시 (로딩 스피너 + 퍼센트)
- ✅ 초기화 완료 후 "로컬 테스트" 버튼 즉시 사용 가능

---

### 2. 타임아웃 기능 테스트

#### 테스트 절차 A: 무한 루프
1. 문제 페이지에서 "로컬 테스트" 탭으로 이동
2. 다음과 같은 무한 루프 코드 작성:
   ```python
   def test_infinite_loop():
       while True:
           pass
   ```
3. "로컬 테스트" 버튼 클릭
4. 5초 후 타임아웃 메시지 확인

#### 기대 결과
- ✅ 5초 후 에러 메시지 표시:
  ```
  실행 시간 초과 (5초). 무한 루프나 과도한 연산이 있는지 확인해주세요.
  ```
- ✅ Worker 자동 재시작
- ✅ 다음 테스트 정상 실행 가능

#### 테스트 절차 B: 과도한 연산
1. 다음과 같은 무거운 연산 코드 작성:
   ```python
   def test_heavy_computation():
       result = sum(range(10**8))
       assert result > 0
   ```
2. "로컬 테스트" 버튼 클릭
3. 타임아웃 여부 확인

#### 기대 결과
- ✅ 5초 이내 완료되면 정상 실행
- ✅ 5초 초과 시 타임아웃 메시지

---

### 3. Worker 재생성 테스트

#### 테스트 절차
1. 무한 루프 코드로 타임아웃 발생시키기
2. Worker 재시작 메시지 확인
3. 정상적인 테스트 코드 작성:
   ```python
   def test_normal():
       assert 1 + 1 == 2
   ```
4. "로컬 테스트" 버튼 재클릭

#### 기대 결과
- ✅ 타임아웃 후 Worker 재생성 완료
- ✅ 정상 코드 실행 성공
- ✅ 에러 메시지 없음

---

### 4. 제출 시스템 회귀 테스트

#### 테스트 절차
1. 정상적인 테스트 코드 작성 (예: VE01 문제)
2. "제출하기" 버튼 클릭
3. 채점 결과 확인

#### 기대 결과
- ✅ 클라이언트 사이드 mutation test 정상 실행
- ✅ 점수 및 mutants killed 정확히 표시
- ✅ 서버 제출 및 피드백 정상 동작

### 5. 성능 검증

#### 측정 지표
- **초기화 시간**: 페이지 진입 → Pyodide 준비 완료 (< 3초 목표)
- **체감 로딩 시간**: "로컬 테스트" 클릭 → 결과 표시 (< 0.5초, 이미 초기화된 경우)
- **타임아웃 정확도**: 무한 루프 → 에러 표시 (5초 ± 0.5초)

#### 측정 방법
1. 브라우저 개발자 도구 → Performance 탭 열기
2. 페이지 로딩 시작
3. Pyodide 초기화 완료까지 시간 측정
4. "로컬 테스트" 실행 시간 측정

## 알려진 제한사항

1. **Worker 타임아웃은 Python 실행 중 취소 불가**
   - Pyodide `runPythonAsync`는 중단 불가
   - setTimeout으로 Promise reject만 가능

2. **초기화 진행률이 단계별로만 표시**
   - Pyodide 자체에서 세밀한 진행률 제공 안 함
   - "로딩 중", "설치 중" 등 단계별 메시지만 표시

3. **Worker 재생성 시 약간의 딜레이**
   - 타임아웃 발생 후 다음 테스트까지 1-2초 소요
   - Pyodide 재초기화 필요

## 문제 해결

### Q1: "환경 로드 실패" 메시지가 계속 표시됨
- **원인**: CDN 연결 실패 또는 네트워크 문제
- **해결**: 페이지 새로고침 후 재시도

### Q2: 타임아웃 후 다음 테스트도 실패함
- **원인**: Worker 재생성 중 즉시 실행 시도
- **해결**: 1-2초 대기 후 재시도 또는 페이지 새로고침

### Q3: 진행률이 멈춰있음
- **원인**: Worker 초기화 중 에러 발생
- **해결**: 브라우저 콘솔 확인 후 에러 리포트
