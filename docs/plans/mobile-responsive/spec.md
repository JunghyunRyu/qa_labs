## 1. 개요

### 배경
- 모바일 사용자 증가에 따른 UI 최적화 필요
- 현재 일부 페이지는 반응형이 적용되어 있으나 완전하지 않음
- 코드 에디터는 모바일 제한적 지원 (데스크톱 권장)

### 목표
- **핵심 3개 페이지** 모바일 UI 최적화: 홈, 문제 목록, 문제 풀이
- 모바일 사용자 경험 개선 (터치 영역, 가독성, 네비게이션)
- 코드 에디터는 "데스크톱에서 풀어보세요" 안내로 제한적 지원

### 범위

| 페이지 | 작업 범위 |
|--------|----------|
| 홈 (/) | 헤더, Hero, CTA 모바일 최적화 |
| 문제 목록 (/problems) | 필터 바 개선, 카드 레이아웃 |
| 문제 풀이 (/problems/[id]) | 기존 MobileTabLayout 유지, 미세 조정 |

### 제외 범위
- Admin 페이지 (/admin/*)
- Monaco Editor 완전 모바일 지원 (비용 대비 효과 낮음)

## 2. 현황 분석

### 이미 구현된 것

| 기능 | 파일 | 설명 |
|------|------|------|
| useMediaQuery | `hooks/useMediaQuery.ts` | mobile/tablet/desktop 브레이크포인트 감지 |
| MobileTabLayout | `components/layout/MobileTabLayout.tsx` | 문제 풀이 탭 기반 레이아웃 |
| MobileNotice | `components/MobileNotice.tsx` | "PC에서 더 편리하게" 안내 배너 |
| Tailwind 반응형 | 전역 | `sm:`, `md:`, `lg:` 클래스 사용 |

### 개선 필요 영역

1. **헤더 (Navbar)**
   - 모바일에서 메뉴 아이템 overflow
   - 햄버거 메뉴 필요

2. **문제 목록 페이지**
   - 필터 바가 모바일에서 가로 스크롤 필요
   - 터치 영역이 작음 (44px 미만)
   - 카드 그리드 1열 처리 필요

3. **홈페이지**
   - Hero 섹션 텍스트 크기 조정
   - CTA 버튼 터치 영역 확대

## 3. 기술 명세

### 브레이크포인트 (기존 유지)

```typescript
// hooks/useMediaQuery.ts
mobile: < 768px
tablet: 768px - 1023px
desktop: >= 1024px
```

### 모바일 디자인 원칙

1. **터치 영역**: 최소 44x44px (Apple HIG 기준)
2. **폰트 크기**: 최소 14px (가독성)
3. **간격**: 터치 가능 요소 간 최소 8px
4. **스크롤**: 가로 스크롤 최소화, 세로 우선
