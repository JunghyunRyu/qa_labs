## 구현 내용

### 변경 파일
1. **신규 파일**: `frontend/components/MobileMenu.tsx` (180줄)
   - 햄버거 버튼
   - 우측 슬라이드-인 드로어
   - 오버레이 배경 (클릭 시 닫기)
   - 홈/앱 페이지 메뉴 분기
   - 사용자 정보 섹션 (앱 페이지)
   - 하단 CTA 영역

2. **수정 파일**: `frontend/components/Header.tsx`
   - `useMediaQuery` import
   - `MobileMenu` import
   - 데스크톱 메뉴에 `hidden lg:flex` 추가
   - 모바일 메뉴 조건부 렌더링

### 주요 기능
- **터치 영역**: 최소 44px 확보 (햄버거 버튼 44x44px, 메뉴 항목 44px 높이)
- **애니메이션**: 300ms ease-in-out 슬라이드
- **Body 스크롤 방지**: 메뉴 열릴 때 `overflow: hidden`
- **라우트 변경 시 자동 닫기**: `pathname` 변경 감지
