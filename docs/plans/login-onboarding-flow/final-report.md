## 로그인 플로우 변경

### Before (기존)
```
신규 사용자: 약관 동의 → /problems?welcome=true
기존 사용자: 로그인 → / (홈페이지)
```

### After (개선)
```
신규 사용자: 약관 동의 → /problems/problem-ve03?onboarding=new → 모달 표시
기존 사용자: 로그인 → /problems/problem-ve03?onboarding=returning → 모달 표시
재방문 (redirect 있음): 기존 동작 유지
```

## 온보딩 모달 메시지

| 타입 | 배지 | 메시지 |
|------|------|--------|
| `new` | 첫 번째 미션 | "30초 만에 첫 버그를 잡아보세요!" |
| `returning` | 다시 오셨네요! | "오늘의 미션부터 시작해볼까요?" |

## 기술적 구현

### 모달 기능
- framer-motion 애니메이션 (scale + fade)
- ESC 키로 닫기
- Body 스크롤 방지
- 다크 테마 (slate-900)
- 52px 터치 영역 확보

### URL 정리
- 모달 닫힌 후 `?onboarding` 파라미터 자동 제거
- `window.history.replaceState` 사용 (새로고침 없음)
