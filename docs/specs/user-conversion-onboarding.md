# 사용자 전환 및 온보딩 개선 스펙

> **작성일**: 2026-01-15
> **상태**: 구현 완료

---

## 배경

Daily Report 분석 결과, 다음 문제점이 발견됨:
- 신규 가입자 2명이 문제를 풀지 않고 이탈
- 익명 사용자 12건의 제출 (회원 제출 0건)

### 원인 분석

| 문제 | 원인 |
|------|------|
| **온보딩 부족** | 가입 후 홈("/")으로만 리다이렉트, 다음 행동 안내 없음 |
| **이탈** | 가입만 하고 뭘 해야 할지 몰라서 이탈 |
| **익명 선호** | 가입은 했지만 로그인 없이 익명으로 문제 풀이 |

---

## 구현 내용

### 1. 온보딩 플로우 개선

#### 변경 사항

| 항목 | Before | After |
|------|--------|-------|
| 가입 후 리다이렉트 | `/` (홈) | `/problems?welcome=true` |
| 웰컴 배너 | 없음 | 신규 가입자용 배너 표시 |
| 첫 미션 유도 | 없음 | "첫 미션 시작" CTA 버튼 |

#### 파일 변경

**`frontend/app/auth/callback/page.tsx`**
```typescript
// 변경: 신규 가입자는 문제 목록으로 직접 이동
router.push("/problems?welcome=true");
```

**`frontend/app/problems/page.tsx`**
- `welcome=true` 파라미터 감지
- 웰컴 배너 컴포넌트 렌더링
- URL에서 파라미터 자동 제거 (새로고침 시 중복 표시 방지)

#### 웰컴 배너 UI

```
┌─────────────────────────────────────────────────────────────┐
│ 🎉 환영합니다! QA Arena에 오신 것을 축하해요               │
│                                                             │
│ 버그 탐지 미션을 통해 테스트 코드 실력을 키워보세요.       │
│ 입문 난이도부터 시작하는 걸 추천드려요!                    │
│                                                             │
│                              [🚀 첫 미션 시작] [X]         │
└─────────────────────────────────────────────────────────────┘
```

### 2. 익명 사용자 전환 유도

#### 변경 사항

| 상태 | 배너 메시지 | CTA |

| **SUCCESS** | "이 결과를 저장하시겠어요?" | 결과 저장하기 |
| **FAILURE** | "실패도 성장의 일부입니다" | 기록 시작하기 |

**`frontend/components/SubmissionResult.tsx`**

## 사용자 여정 (개선 후)

### 신규 가입자 플로우

```
[가입] → [약관 동의] → [문제 목록 + 웰컴 배너] → [첫 미션 시작]
                              │
                              └── 튜토리얼 모달도 함께 표시
```

### 익명 사용자 전환 플로우

```
[익명으로 문제 풀이] → [제출] → [결과 + 로그인 유도 배너]
                                        │
                        ┌───────────────┴───────────────┐
                        │                               │
                   [SUCCESS]                       [FAILURE]
                   "결과 저장하기"                "기록 시작하기"
                        │                               │
                        └───────────────┬───────────────┘
                                        │
                                    [GitHub 로그인]
                                        │
                                    [회원 전환]
```

## 향후 개선 가능 사항

### Phase 2 (선택적)

1. **이메일 리마인더**
   - 가입 후 24시간 내 문제 안 풀면 리마인드 이메일

2. **첫 문제 완료 보상**
   - 첫 성공 시 보너스 토큰 지급

3. **온보딩 진행률 표시**
   - 프로필 완성도, 첫 문제, 첫 100점 등 체크리스트

4. **A/B 테스트**
   - 배너 문구/디자인 테스트로 전환율 최적화
