## Easy 난이도

### 대상
- **경력**: 0-1년차, 테스트 입문자
- **배경**: 기본 pytest 사용 가능, 테스트 개념 이해 중

### 함수 복잡도
| 항목 | 기준 |
|------|------|
| 파라미터 수 | 1-3개 |
| 조건 분기 | 1-3개 |
| 반환 타입 | 단순 (bool, int, str) |
| 외부 의존성 | 없음 |
| 상태 관리 | 없음 (순수 함수) |

### 필요한 테스트 기법
| 기법 | 필수 | 설명 |
|------|-----|------|
| 경계값 분석 | ✅ | 0, 1, N-1, N, N+1 |
| 동등 분할 | ✅ | 유효/무효 클래스 |
| 예외 처리 | ✅ | pytest.raises 사용 |
| 파라미터화 | ⭕ | 선택적 |

### 뮤턴트 특성
| 항목 | 기준 |
|------|------|
| 개수 | 3-4개 |
| 유형 | 단순 버그 (비교 연산자, 예외 누락) |
| 발견 난이도 | 기본 테스트로 발견 가능 |
| weight 분포 | 3-5 (합계 12-16) |

### 예상 풀이 시간
- **목표**: 10-15분
- **최소**: 5분 (숙련자)
- **최대**: 25분 (초보자)

### description_md 스타일
- 친절한 설명
- 힌트 풍부
- 예제 코드 포함
- 테스트 기법 안내

### 예시 문제
- `can_withdraw`: 출금 가능 여부 (경계값, 예외)
- `validate_age`: 나이 검증 (범위, 타입)
- `is_palindrome`: 회문 검사 (문자열, 엣지케이스)

## Medium 난이도

### 대상
- **경력**: 1-3년차, 실무 경험 있는 QA
- **배경**: 다양한 테스트 기법 활용, Mock 사용 가능

### 함수 복잡도
| 항목 | 기준 |
|------|------|
| 파라미터 수 | 3-5개 |
| 조건 분기 | 4-7개 |
| 반환 타입 | 복합 (dict, list, tuple) |
| 외부 의존성 | 있을 수 있음 (Mock 필요) |
| 상태 관리 | 단순 상태 (선택적) |

### 필요한 테스트 기법
| 기법 | 필수 | 설명 |
|------|-----|------|
| 경계값 분석 | ✅ | 다중 경계값 |
| 동등 분할 | ✅ | 복합 클래스 |
| 예외 처리 | ✅ | 다양한 예외 타입 |
| 파라미터화 | ✅ | @pytest.mark.parametrize |
| 조합 테스트 | ✅ | 조건 조합 |
| Mock/Stub | ⭕ | 외부 의존성 있을 때 |

### 뮤턴트 특성
| 항목 | 기준 |
|------|------|
| 개수 | 4-5개 |
| 유형 | 조합 버그, 정책 오류, 불완전 검증 |
| 발견 난이도 | 조합 테스트로 발견 필요 |
| weight 분포 | 3-5 (합계 15-22) |

### 예상 풀이 시간
- **목표**: 20-30분
- **최소**: 15분 (숙련자)
- **최대**: 45분 (초보자)

### description_md 스타일
- 핵심 포인트 명시
- 일부 힌트만 제공
- 조합 패턴 암시
- 스스로 발견 유도

### 예시 문제
- `is_valid_email`: 이메일 검증 (다중 규칙, 경계값)
- `calculate_discount`: 할인 계산 (조합, 우선순위)
- `validate_datetime`: 날짜/시간 검증 (포맷, 범위)

## Hard 난이도

### 대상
- **경력**: 3년차+, 시니어 QA
- **배경**: 복잡한 시스템 테스트 경험, 상태 기반 테스트 가능

### 함수 복잡도
| 항목 | 기준 |
|------|------|
| 파라미터 수 | 4개 이상 |
| 조건 분기 | 8개 이상 |
| 반환 타입 | 복합 (중첩 dict, 커스텀 객체) |
| 외부 의존성 | 복잡 (다중 Mock, 시간/랜덤) |
| 상태 관리 | 복잡 상태, 상태 전이, 부수효과 |

### 필요한 테스트 기법
| 기법 | 필수 | 설명 |
|------|-----|------|
| 경계값 분석 | ✅ | 다층 경계값, off-by-one |
| 동등 분할 | ✅ | 복잡한 분할 기준 |
| 상태 기반 | ✅ | 상태 전이, 조합 |
| Mock/Stub | ✅ | 시간, 랜덤, 외부 API |
| 부수효과 검증 | ✅ | 입력 변경, 상태 누출 |
| 비결정성 테스트 | ⭕ | 시간/랜덤 의존 |

### 뮤턴트 특성
| 항목 | 기준 |
|------|------|
| 개수 | 5-6개 |
| 유형 | 미묘한 상태 버그, hidden state, 규칙 조합 오류 |
| 발견 난이도 | 심층 분석, 상태 기반 테스트 필요 |
| weight 분포 | 3-5 (합계 18-26) |

### 예상 풀이 시간
- **목표**: 40분 이상
- **최소**: 30분 (숙련자)
- **최대**: 60분+

### description_md 스타일
- 핵심 명세만 제공
- 최소 힌트
- 흐름도/다이어그램 필수
- 코드 스켈레톤 제공

### 예시 문제
- `calculate_cart_total`: 다층 할인 계산 (상태, 조합, 부수효과)
- `process_transaction`: 트랜잭션 처리 (상태 전이, 롤백)
- `schedule_task`: 스케줄링 (비결정성, 시간 의존)

## 테스트 기법 난이도 매핑

### 기법별 난이도
| 기법 | 난이도 | 설명 |
|------|--------|------|
| 단순 assert | Easy | `assert result == expected` |
| pytest.raises | Easy | 예외 발생 검증 |
| 경계값 분석 | Easy | 0, 1, N-1, N, N+1 |
| 동등 분할 | Easy | 유효/무효 클래스 |
| @pytest.mark.parametrize | Medium | 파라미터화 테스트 |
| Mock/Stub | Medium | `unittest.mock` |
| 조합 테스트 | Medium | 다중 조건 조합 |
| 상태 기반 테스트 | Hard | 상태 전이 검증 |
| 부수효과 검증 | Hard | 입력 mutation 체크 |
| 비결정성 테스트 | Hard | 시간/랜덤 모킹 |

### 난이도별 필수 기법 수
| 난이도 | 필수 기법 수 |
|--------|-------------|
| Easy | 2-3개 |
| Medium | 4-5개 |
| Hard | 6개+ |

## 뮤턴트 유형별 난이도

### Easy 뮤턴트
```python
# 비교 연산자 오류
return amount < balance  # 대신 <=

# 예외 누락
if amount < 0:
    return False  # 대신 raise ValueError

# 경계값 오류
if qty > 10:  # 대신 >= 10
```

### Medium 뮤턴트
```python
# 조건 조합 누락
if '..' in local:  # domain의 '..'는 체크 안 함
    return False

# 정책 해석 오류
if len(local) >= 64:  # 대신 > 64 (off-by-one)
    return False

# 불완전 검증
if not isinstance(email, str):
    return False  # 대신 raise TypeError
```

### Hard 뮤턴트
```python
# 상태 조합 오류
if coupon is not None and (not stackable_with_vip):
    vip_rate = 0  # coupon_applicable 조건 누락

# Hidden State
if code in calculate_cart_total._redeemed_codes:
    raise ValueError  # 전역 상태 오염

# 정책 위반 (미묘)
coupon_applicable = subtotal_cents >= min_subtotal
# 대신 eligible_subtotal_cents (gift_card 제외)
```

## 난이도 조정 체크리스트

### Easy로 낮추려면
- [ ] 파라미터 수 줄이기
- [ ] 조건 분기 단순화
- [ ] 뮤턴트를 단순 버그로
- [ ] 힌트 추가

### Medium으로 올리려면
- [ ] 조합 테스트 필요하게 만들기
- [ ] 뮤턴트에 조건 조합 버그 추가
- [ ] Mock 필요 요소 추가
- [ ] 힌트 줄이기

### Hard로 올리려면
- [ ] 상태 관리 복잡도 추가
- [ ] 숨겨진 상태/부수효과 뮤턴트 추가
- [ ] 비결정적 요소 추가
- [ ] 힌트 최소화
